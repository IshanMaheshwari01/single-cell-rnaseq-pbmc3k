Single-cell RNA-seq of 2,700 PBMCs

Scanpy analysis of the 10x Genomics PBMC 3k dataset: QC, clustering, marker genes and 8 immune cell types recovered from raw counts.

code on GitHub · README

Annotated cell types on the UMAP

2,638 cells after QC, coloured by the cell type assigned from marker-gene scores. From the standard Scanpy workflow: QC, normalisation, 1,838 highly variable genes, PCA, kNN graph, Leiden clustering.

Cells per type

T cells dominate, as expected in peripheral blood. Megakaryocytes are the rare population (13 cells) and still form their own cluster.
